# 🚀 Mini Projects

A collection of small beginner-friendly web projects built with **HTML, CSS, and JavaScript**. Each project lives in its own folder and focuses on practicing core front-end concepts like DOM manipulation, event handling, and basic logic.

## 📂 Projects

| Project | Description |
|---------|-------------|
| **Counter** | Increase, decrease, and reset a number with button clicks |
| **Guess a Num** | Guess the randomly generated number within limited attempts |
| **Stopwatch** | Start, stop, and reset a timer |
| **Chess Board** | A chess board generated with JavaScript |
| **Color Spotter** | Spot the odd-colored tile in a grid |
| **Star Rating** | Interactive star-based rating component |
| **String Transform** | Transform text (upper case, lower case, reverse, etc.) |
| **Telephone Formatter** | Formats a phone number input into a readable pattern |
| **Tic-Tac-Toe** | Classic two-player X and O game |
| **Todo List** | Add, complete, and delete daily tasks |
| **Weather App** | Search a city and view its current weather |

## 🛠️ Tech Stack

- **HTML5**: structure
- **CSS3**: styling and layout
- **JavaScript (ES6)**: logic and interactivity

## ▶️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/barnwal6201-eng/mini-projects.git
   ```
2. **Navigate into a project folder**
   ```bash
   cd mini-projects/Counter
   ```
3. **Open `index.html`** in your browser (or use the VS Code *Live Server* extension).

> Note: The Weather App may require a free API key. Add your key in its JavaScript file before running.
